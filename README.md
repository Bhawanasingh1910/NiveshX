# NiveshX
**A full-stack investment and trading platform built to make investing information simple, organized, and easy to explore.**

🔗 **Live Project:** https://nivesh-x-q1dg.vercel.app/

-------------------------

## What is NiveshX?

* NiveshX is a full-stack web project inspired by the experience of modern investment platforms.
* It combines a clean landing website with an interactive trading dashboard where users can explore their portfolio, view holdings, check positions, and place demo orders.
* The main idea was to build more than just a frontend — NiveshX connects the **website, dashboard, backend APIs, and MongoDB database** into one working application.

-------------------------

##  What can you do with NiveshX?

###  Website
The main website introduces the NiveshX platform and provides information about its features.

* **Home** — Introduction to NiveshX and quick access to the platform
* **Products** — Explore the different investment and trading areas
* **Pricing** — Understand the project's demo brokerage structure
* **About** — Learn about NiveshX and the technology behind it
* **Support** — Browse common help topics and support information
* **Sign Up** — Create an account through the project's demo signup flow


## Trading Dashboard
The dashboard is where the main investing experience happens.

* **Dashboard** -- A quick overview of the user's investment activity and portfolio.
* **Watchlist** -- Keep an eye on selected stocks and quickly access their trading actions.
* **Holdings** --View the stocks currently held in the portfolio along with their quantities, prices, and overall portfolio information.
Holdings data is connected to the backend and stored in MongoDB.
* **Positions** --View current trading positions and their associated information.
* **Orders** --View the order section and track trading activity.
* **Funds** --A dedicated section for viewing available funds and account-related financial information.
* **Buy Orders** --The dashboard includes a demo buy-order flow where users can enter the quantity and price of a stock.
The order is sent to the backend and stored in the database.
* **Portfolio Chart** --Holdings are also represented visually through a chart to make portfolio information easier to understand.

---------------------------

## How the Project Works

NiveshX connects three major parts:

  **Website  →  Trading Dashboard  →  Backend API  →  MongoDB Database**

The frontend and dashboard are built with **React**, the backend is powered by **Node.js and Express**, and MongoDB is used to store application data.
This makes NiveshX a complete **frontend + backend + database** project rather than a static website.
